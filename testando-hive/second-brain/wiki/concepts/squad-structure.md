# Squad Structure

## Definition

An organizational model where development teams (squads) are organized around domain responsibilities. Each squad owns specific applications or features and the specialists within it have defined expertise areas.

## Key Elements

- **Squad ownership:** Clear responsibility for specific applications or services
- **Specialist roles:** Team members with defined expertise (e.g., frontend specialists)
- **Focused scope:** Squad manages related but distinct applications/features

## Example: Hub Squad

The [[Hub Squad]] exemplifies this structure:
- **Specialty:** Frontend development
- **Scope:** Three related webview and hub applications
- **Specialists:** [[Gustavo]] (frontend specialist)
