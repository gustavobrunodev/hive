O que é

Um harness preciso, não um harness grande

Harness é o conjunto de controles que faz o agente acertar mais na primeira tentativa e se autocorrigir no resto: guides orientam antes de agir, sensors dão feedback depois. O Harness Builder monta esse sistema seguindo um princípio só.

Guiado por harness engineering

A harness-engineer é a espinha

O módulo harness-engineer avalia o projeto e decide o que realmente precisa antes de tocar em qualquer arquivo. Os outros módulos entram a serviço dele.

Sem overengineering

Cada controle merece seu lugar

Toda rule, sensor e skill precisa atacar uma falha real e observada. Na dúvida, o playbook refina ou remove; nunca acumula ruído.

Evolui com o projeto

Harness não é evento único

Nova biblioteca, MCP ou falha recorrente? A skill avalia se entra no harness — como rule, skill, sensor ou nada — sem acumular ruído.

Quando usar

Setup inicial e evolução contínua

O harness não termina na primeira entrega. A skill vive com o projeto — e responde tanto ao playbook completo quanto a pedidos pontuais conforme o contexto muda.

Quando o escopo é montar ou revisar o harness inteiro, a harness-engineer conduz o fluxo. Os demais módulos entram só para lacunas que a avaliação identificou — no dia a dia, pedidos pontuais usam um módulo só.

O que vem dentro

Quatro módulos, um maestro

Cada módulo é uma cópia fiel da skill original, preservada em references/ para seguir independente. A harness-engineer é a única que decide; as outras três executam o que a avaliação dela pediu.

Espinha

harness-engineer

Avalia o harness, classifica cada controle, define sensores e fecha o steering loop. Decide o que cada uma das outras skills faz e onde cada controle roda.

O princípio

Menos retrabalho, mais precisão

Um harness que dispara ruído que ninguém trata é pior do que um menor em que o agente confia. Por isso cada controle precisa merecer seu lugar — no setup e em cada evolução — e a skill sempre prefere refinar a acumular.

!

Sensores verificam forma e pegam regressões, não verificam intenção. O harness redireciona a atenção humana para onde ela importa; não a elimina.
