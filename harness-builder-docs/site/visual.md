# visual.md — Identidade visual Zup

## Paleta de cores

### Primária

| Nome              | HEX                   | Uso                                     |
| ----------------- | --------------------- | --------------------------------------- |
| Bordô Excelência  | `#260A12`             | Fundo principal, base de slides escuros |
| Cinza Impacto     | `#DED4D4`             | Fundo claro, contraste com Bordô        |
| Gradiente Conexão | `#5C1C27` → `#260A12` | Fundos com gradiente, transições        |

### Complementar (apenas detalhes — nunca como fundo predominante)

| Nome               | HEX       | Uso                                 |
| ------------------ | --------- | ----------------------------------- |
| Bordô Sensatez     | `#852838` | Destaque de palavras em fundo Bordô |
| Cinza Conhecimento | `#AD9797` | Textos secundários, detalhes sutis  |
| Coral Ousadia      | `#CC7958` | Destaque sobre fundo Cinza Impacto  |

### Semântica de cor (funcional, nunca decorativa)

- **Verde** `#52C998` — crescimento, resultado positivo, NPS alto
- **Vermelho** — atenção, custo crescendo, desvio de meta
- **Âmbar** — neutro, estável, variação pequena

### Regras de aplicação

- Combinação preferencial: fundo **Bordô Excelência** + texto em **Cinza Impacto**
- Combinação secundária: fundo **Cinza Impacto** + texto em **Bordô Excelência**
- Destaque de palavras: **Bordô Sensatez** sobre Bordô; **Coral Ousadia** sobre Cinza
- Gradiente: difusão com pontos ou dispersão — nunca gradiente linear ou radial simples
- Fundo padrão de slides claros: `#F5F0F0` (variação suave do Cinza Impacto)

## Tipografia

### Fontes oficiais

| Fonte          | Uso                       | Pesos               |
| -------------- | ------------------------- | ------------------- |
| Funnel Display | Títulos e chamadas        | SemiBold, Bold      |
| Inter          | Textos, subtítulos, listas | Regular, SemiBold, Bold |
| Inter Tight    | Numeração e destaque ≥37pt | Bold                |

### Hierarquia nos slides

| Elemento              | Fonte          | Peso     | Tamanho sugerido |
| --------------------- | -------------- | -------- | ---------------- |
| Título do slide       | Funnel Display | Bold     | 36–44pt          |
| Subtítulo / chamada   | Funnel Display | SemiBold | 24–32pt          |
| Corpo de texto        | Inter          | Regular  | 16–20pt          |
| Bullets e listas      | Inter          | Regular  | 14–18pt          |
| Legendas e rodapés    | Inter          | Regular  | 10–12pt          |
| Destaque inline       | Inter          | SemiBold | mesmo do corpo   |

### Fallback

- Funnel Display → Georgia ou Playfair Display
- Inter → Helvetica Neue ou Arial

### Regras tipográficas

- Títulos com maiúscula inicial — nunca ALL CAPS em textos corridos
- Períodos curtos — ritmo de leitura e clareza
- Linguagem inclusiva — sem generalizações no masculino
- Sem emojis em materiais institucionais

## Elementos visuais proprietários

### Formas
- Retângulos com cantos cortados diagonalmente (formas proprietárias Zup)
- Diagonais voltadas à direita — evocam agilidade, movimento e progresso
- Usos: máscaras para fotos, suporte para textos, botões, padrões

### Grafismos Cocriação
- Dois elementos próximos que transmitem conexão e avanço
- Gradiente `#5C1C27` suaviza o início do traço
- Uso preferencial sobre fundo Bordô Excelência
- Ideal para transições de vídeo e frases de impacto

### Símbolo "Z"
- Versão robusta (com caixa): maior presença, fundos variados
- Versão minimalista (sem caixa): leveza, modernidade
- Nunca rotacionar, distorcer, inverter ou aplicar sombras

## Estrutura padrão dos slides

### Cabeçalho
- Título no canto superior esquerdo (Funnel Display Bold, Bordô Excelência)
- Linha decorativa Coral Ousadia abaixo do título

### Rodapé
- Esquerda: `@zupinnovation` | Direita: `zup.com.br`
- Inter Regular, pequeno, Cinza Conhecimento

## Componentes visuais disponíveis

- **Cards com ícone** — grid 2×2, bordas diagonais, ícone em Bordô Sensatez
- **Lista numerada** — numeração Coral Ousadia, separadores pontilhados, 2 colunas
- **Tabela comparativa** — formas proprietárias, badge colorido, título Coral Ousadia
- **Timeline horizontal** — pontos Bordô Sensatez, anos alternados, atual em Coral Ousadia
- **Gráfico de Gantt** — barras em degradê Bordô, header em pills Bordô Sensatez

---

## O que nunca fazer visualmente

- Não alterar cores, fontes ou proporções da assinatura visual
- Não aplicar gradientes lineares ou radiais simples
- Não usar as cores complementares como cor predominante de fundo
- Não misturar fontes fora da hierarquia estabelecida
- Não inverter, rotacionar ou aplicar sombra no logotipo
