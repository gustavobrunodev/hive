# orders-api

Node + TypeScript service for order intake.

## Commands

- `npm run verify` — typecheck + lint + test. Run before calling anything done.

## Onde está o resto

- `.specs/project/STATE.md` — memória viva (decisões + lições) — **leia antes de começar**.
- `.specs/project/HARNESS.md` — o que guia e o que mede o agente, e o que
  deliberadamente não existe — **atualize quando mudar um controle**.
