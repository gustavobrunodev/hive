# Icones

O conjunto de ícones do estúdio: traço de 1.75 em grade de 24, pontas e junções arredondadas, sem preenchimento (exceto `mais3`). Os arquivos levam a tinta do tema claro (#1a1a1a); em código, use o mesmo desenho com `stroke="currentColor"` e a classe `ic`, para o ícone seguir a cor do texto (`tinta-2` na maior parte da interface, `acento-tinta` no item atual). Tamanhos: 17px em botões, 18px na lateral, 13px em pílulas.
