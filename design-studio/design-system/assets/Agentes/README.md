# Agentes

As marcas oficiais dos agentes, para usar só dentro do ladrilho `ag-logo`. `claude.svg` tem a cor própria da marca (`marca-claude`, #d97757). A marca do Devin é monocromática: `devin.svg` leva tinta clara (#1a1a1a) para fundos claros e `devin-claro.svg` leva #f2f2ee para o tema escuro; em código, prefira o caminho com `fill="currentColor"` para seguir `tinta`.
