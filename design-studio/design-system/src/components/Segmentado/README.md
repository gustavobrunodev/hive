Grupo de escolha curta e exclusiva: Produto no Início, período nos Gráficos, tema claro ou escuro, Antes ou Depois e tamanho no Inserir.

## Use
Para duas a quatro opções que trocam a vista na hora.
- **`forma="padrao"`**: trilho `superficie-3`; a opção marcada sobe para `superficie` com `sombra-1` e peso 600.
- **`forma="pill"`**: o alternador de tema, só ícones, trilho `superficie-2` com borda.
- **`forma="compacto"`**: as escolhas curtas do `PainelFlutuante` (Antes/Depois, P/M/G, 1 a 4).

## O consumidor fornece
As `opcoes` (valor, rótulo, ícone opcional, `soIcone`), o `valor` atual, `aoMudar` e o `rotulo` do grupo, que é o nome acessível. Cada opção é um `<button aria-pressed>`.

## Não
Mais de quatro opções viram um `Seletor` com menu.
