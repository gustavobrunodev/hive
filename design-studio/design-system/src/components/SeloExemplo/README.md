O selo "Dados de exemplo" que acompanha todo dado sintético.

## Use
Sempre que a tela mostra Dores, Relatórios ou números que não são de clientes reais.
- **`forma="linha"`**: na lateral aberta, uma linha discreta com ponto `acento` de 7px e texto em `tinta-3`.
- **`forma="pill"`**: no cabeçalho, quando a lateral está recolhida ou no celular. Pill `superficie` com borda `borda` e texto em `tinta-2`.

## O consumidor fornece
Onde mostrar o selo. O texto padrão é "Dados de exemplo".

## Não
Não remova o selo para "limpar" uma demonstração: ele é o que torna os números honestos.
