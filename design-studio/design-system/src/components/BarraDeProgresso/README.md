A barra de progresso do estúdio: enquanto o agente gera Variantes ou monta um Protótipo.

## Use
6px de altura, trilho `superficie-3`, progresso em `acento`, que anda em 0.4s. Atualize o valor no lugar, sem remontar o painel, para o `CursorDoAgente` não voltar ao início.

## O consumidor fornece
O `valor` de 0 a 1 e o `rotulo`, que é o nome acessível da `progressbar`.
