As marcas oficiais de Claude e Devin num ladrilho neutro, para identificar quem respondeu, quem está trabalhando e quem escreveu um insight.

## Use
- **`tamanho="normal"`** (24px, svg de 15px): cabeçalho da mensagem, seletor de agente, menu de agente.
- **`tamanho="pequeno"`** (20px): autoria do insight.
- **`tamanho="grande"`** (40px, svg de 24px): Configurações.

O ladrilho é `superficie` com borda `borda`. A marca do Claude usa a cor própria (`marca-claude`); a do Devin é monocromática e segue `tinta`.

## O consumidor fornece
O `agente` e, quando o nome não estiver escrito ao lado, `anunciar` para o leitor de tela dizer quem é.

## Não
A logo identifica, não decora: não recolora, não use fora do ladrilho, não conte como acento.
