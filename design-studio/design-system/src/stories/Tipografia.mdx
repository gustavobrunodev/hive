# Tipografia

Duas famílias, servidas como arquivo com a lib: Geist (`--f-ui`) para toda a interface e Bricolage Grotesque (`--f-titulo`, com eixo óptico) só onde o quadro fala com a pessoa. Bricolage nunca entra em botões, campos, listas ou corpo de texto; rótulos ficam em Geist 600, em caixa normal.
