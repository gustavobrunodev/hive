# Toast

Aviso curto e invertido que confirma o que acabou de acontecer e some em 3s.

## Use
Depois de uma ação que muda o Protótipo ("Elemento inserido · Ponto de restauração criado", "Variantes descartadas. Nada mudou."). Fundo `toast`, texto `sobre-toast`, ícone em `acento`, canto `raio-pill`, `sombra-3`; `role="status"`. Na vista de trabalho fica centrado no canvas, acima das ferramentas; nas outras, no canto inferior direito.

## O consumidor fornece
O texto e, se não for confirmação, um ícone do conjunto (`info`, `alerta`).

## Não
Um aviso por vez: ao trocar de vista, os anteriores saem.
