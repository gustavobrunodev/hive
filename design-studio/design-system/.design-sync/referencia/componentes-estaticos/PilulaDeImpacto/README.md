# PilulaDeImpacto

O impacto de uma Dor em três níveis, sempre com ícone e palavra.

## Use
- **`pilula imp-alto`**: `critico` cheio com texto branco (5,70:1 no claro, 4,69:1 no escuro).
- **`pilula imp-medio`**: `atencao` com `atencao-tinta`.
- **`pilula imp-baixo`**: `observar` com `observar-tinta`.

Geist 600 0.75rem, canto `raio-pill`, ícone de 13px. Dentro das notas autoadesivas a versão é a translúcida `nota-imp` (ver `NotaAutoadesiva`).

## Não
O nível nunca vai só na cor: o ícone e a palavra ficam sempre.
