# SeloExemplo

O selo "Dados de exemplo" que acompanha todo dado sintético.

## Use
Sempre que a tela mostra Dores, Relatórios ou números que não são de clientes reais. Na lateral aberta é uma linha discreta (`lat-exemplo`, ponto `acento` de 7px e texto em `tinta-3`). Com a lateral recolhida ou no celular, sobe para o cabeçalho como pill (`selo-exemplo`, `superficie`, borda `borda`, texto `tinta-2`), que fica oculta fora desses casos.

## Não
Não remova o selo para "limpar" uma demonstração: ele é o que torna os números honestos.
