# FiltroDeGraficos

A linha de filtros acima dos Gráficos do Relatório: período e Dor.

## Use
`Segmentado` de período (90, 60, 30 dias) e um seletor de Dor de 38px (`graf-dor`): canto `raio`, borda `borda-forte`, rótulo "Dor" em `tinta-3`, opções agrupadas por categoria. "Limpar filtro" (`btn btn-ter`) aparece só quando há recorte.

## O consumidor fornece
Os períodos, as Dores agrupadas por categoria e o recorte atual. Os gráficos abaixo leem o mesmo estado.
