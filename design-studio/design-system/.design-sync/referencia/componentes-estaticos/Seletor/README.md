# Seletor

Pill de 34px que abre um menu de escolha no campo do chat: agente e modelo, Protótipo.

## Use
Para escolhas que mudam o contexto do que vai ser enviado (com qual agente, em qual Protótipo). Fundo `superficie-2`, borda fina, ícone em `tinta-2`, canto `raio-pill`.

## O consumidor fornece
Um `<button class="pill">` com `aria-haspopup="menu"`, ícone ou logo do agente à esquerda, o valor atual e a seta. O menu que abre usa `elevada` e `sombra-3`.

## Não
Não use o seletor para ações; ação é `Botao`.
