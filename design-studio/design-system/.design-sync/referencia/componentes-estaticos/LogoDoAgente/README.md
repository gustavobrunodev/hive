# LogoDoAgente

As marcas oficiais de Claude e Devin num ladrilho neutro, para identificar quem respondeu, quem está trabalhando e quem escreveu um insight.

## Use
- **`ag-logo ag-claude | ag-devin`**: 24px, `superficie`, borda `borda`, canto `raio-s`, svg de 15px. No cabeçalho da mensagem, no seletor de agente, no menu de agente e na autoria do insight (20px).
- **`ag-grande`**: 40px, canto `raio`, svg de 24px, nas Configurações.

A marca do Claude usa `marca-claude`; a do Devin é monocromática e segue `tinta` (`currentColor`). Os arquivos estão no grupo de assets Agentes.

## Não
A logo identifica, não decora: não recolora, não use fora do ladrilho, não conte como acento.
