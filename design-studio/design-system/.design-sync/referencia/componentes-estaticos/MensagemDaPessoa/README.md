# MensagemDaPessoa

O que a pessoa disse ou fez: balão de texto com as Dores citadas, ou o registro de uma seleção feita no canvas.

## Use
- **Balão** (`msg usuario` > `msg-bolha`): alinhado à direita em `superficie-3`; as Dores citadas vão abaixo como `chip-dor` (`msg-citas`).
- **Seleção** (`msg-selecao`): o elemento escolhido no Editar, ou o ponto de inserção do Inserir, com o pedido em `tinta-2`; a hora diz a origem ("Ponto de inserção no canvas · 11:14").

## O consumidor fornece
O texto ou a seleção (elemento, ação, pedido), as Dores citadas e a hora.
