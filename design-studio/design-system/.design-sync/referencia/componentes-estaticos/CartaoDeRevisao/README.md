# CartaoDeRevisao

O cartão em que o agente devolve uma revisão: um título e uma linha por achado, com o nível à esquerda.

## Use
Para resultados estruturados do agente dentro da conversa (revisão de usabilidade, checagem de acessibilidade). Fundo `superficie`, borda `borda`, canto `raio-painel`; título num cabeçalho recuado em `superficie-2`; achados separados por `borda` no topo, cada um com uma pílula de nível (Resolvido em `ok-suave`/`ok-tinta`, Alto, Médio).

## O consumidor fornece
O título e os achados: nível e frase.
